# Enterprise Theme

This Module adds a new Theme changing the look and fell of the Software completely.
Meant for professional users and larger organisations it does not only change the design, but also adds features to the software to improve the structure of it.

## Overview

- Adds completely new Theme with the navigation on the left side of the screen
- Enlarges the area reserved for contributions to almost the entire screen
- Adds Space Types which enable you to categorize Spaces
- Adds new global permission (User X can create Spaces of Typ: Name1)
